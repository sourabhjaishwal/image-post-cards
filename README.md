# Image Post Cards

A simple Instagram-style image post layout built using HTML and CSS.

## Description

This project displays three image post cards side by side in the center of the page.
Each card includes:

- an image
- a title
- a short description

It is a beginner-friendly frontend project focused on layout, spacing, and responsive design.

## Features

- Centered layout
- Three cards side by side
- Image, title, and description
- Clean white space between image and text
- Smooth hover effect
- Responsive design
- Built with only HTML and CSS

## Technologies Used

- HTML5
- CSS3

## Folder Structure

```bash
image-post-cards/
├── assets

```

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. View the centered image post cards layout.

## What I Learned

- How to center content horizontally and vertically
- How to keep cards in one row using `justify-content`
- How to add spacing between image and content
- How to create smooth hover animations
- How to make a layout responsive
